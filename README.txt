DevOps Final Year Project - Node.js + GitHub Actions + Render.com

Steps to Run:

1. Push this folder to a new GitHub repository.
2. GitHub Actions will automatically trigger the CI/CD pipeline.
3. Deploy the app to Render.com or Railway.app by connecting your GitHub repo.

No need for Docker, Jenkins, or Kubernetes locally.

Files:
- app/server.js: Simple Express server
- app/package.json: Dependencies
- .github/workflows/ci-cd.yml: GitHub Actions pipeline
